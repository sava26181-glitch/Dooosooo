# Telegram-бот

## Render
Environment Variables:
- BOT_TOKEN — токен от BotFather
- OWNER_ID — Telegram ID владельца бота

Команда `/panel` доступна только владельцу и не показывается обычным пользователям.

## Панель администратора
Владелец пишет:
`/panel`

Там:
- Добавить администратора
- Удалить администратора
- Список администраторов

Чтобы добавить/удалить администратора, бот просит числовой Telegram ID.

Все обычные сообщения пользователей, отправленные через «Написать сообщение администратору», приходят в личные сообщения владельцу и всем добавленным администраторам.

Любой администратор может ответить пользователю через Reply на пересланное сообщение.
